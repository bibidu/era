### 封面动词要白话，别用行话当钩子

行话可以极少量存在于正文知识点里，但封面大标题优先「大家一眼就懂」：

| 偏行话 | 更接地气 |
| --- | --- |
| 冲了 / 门冲 | 正对 / 对着 |
| 关不住 | 留不住 / 捂不住 / 兜不住 |
| 受冲、直冲 | 正对 |

例：`大门冲了这三样，钱财关不住` → `大门正对这三样，钱财留不住`（已验证：3189 播放、划走 25.1%）。

### 专名怎么用

- 可搜、用户会搜的：床位、大门、文昌位、缺角、鱼缸 → **标题里保留**
- 流派口诀/术语（火烧天门、门冲）：可进正文或副信息；**别拿最生僻的字当封面动词**，除非像「火烧天门」已被数据验证能带播放

## §受众（比图文号年长很多）

- 年龄：**50 以上 / 41-50 / 31-40** 交替居首（近 8 篇 31-40 与 50 以上并列）。
- 地域：**广东**居首（近 8 篇多次），新一线为主。
- 职业：白领为主，制造业 / 服务业 / 农林牧渔 / 非工作人员 交替。
- 性别：后台常未提取到明确男女占比，暂缺。
- 同类作者（找选题空白）：林旭易学、刘老师户型解析、郭璞研究会、武当丸子、东方术数、哲学本质论、朱汉宇日子馆，以及泛流量的涂磊/新闻姐/人民网。

**动作**：写给「关心自家住宅、想照着调一调」的中年及以上受众；术语首现一句话解释；多给能对照自家的判断句。

## §标签（话题）写法

抖音标签不承担主分发（推荐靠算法读内容），作用是**被搜到** + 内容归类。固定 **3–5 个**，别堆空泛国学词。
结构：1–2 个**可搜具体词**（跟本期主题，如 #卧室风水 #床位摆放 #鱼缸风水）+ 1 个垂类池词（#家居风水/#阳宅风水）+
1 个爆款验证的大词（#传统文化涨知识）+ 可选 1 个自建栏目词（#阳宅篇）。
少用：一次堆 5 个以上；全是「#国学智慧认知觉醒」这类无人搜的空泛词。

## §脚本已知局限（非数据结论，供下次运行排障）

- `fengdashi-analyze.mjs` 的 `openSeries()` 按**标题去掉「（上/中/下篇）」后的完全相等**匹配连载，一旦上/下篇标题措辞不同（如《家里六大煞，一件物就化（上篇）》配《化煞物这样对症用，记牢四禁忌（下篇）》），会误报「未收尾连载」——实际该系列已在 2026-08-10 用《化煞物…（下篇）》接住上篇预告（内容对得上：三件万能化煞物 → 对症处方+四禁忌）。**每次报告出现「未收尾连载」时，先去数据库核对该上篇预告的内容是否已被近期某篇标题不同但内容对应的记录接住**，不要机械按标题字符串判断。
- `scripts/export-pages-with-bgs.mjs` 原来硬编码只识别 `caishen-bg-*.png/jpg` 命名的背景图（历史上是从财神号脚本复制而来），且没有带 `X-Era-Auth` 鉴权头会被本地 Agent 401 拒绝。已修复：现在会自动识别 `--bg-dir` 下任意 png/jpg（无 `caishen-bg-` 前缀也可），并复用 `era-auth-core.mjs` 的内置鉴权哈希。
- `GenerateImage`：2026-08-11 曾被判定「非用户明确请求」整轮拦截；2026-08-12 本轮恢复可用。若再被拦，可回落 `POST /v1/projects/:id/export`（不设 `backgroundType: reference`），靠内置 `pageOverlay: fengshui` 默认纹理交差，并在 publish.json `highlights` 注明缺专属插画。
