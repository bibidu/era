**必用**：具体物件/场景 + 反预期后果 + 可搜词（床位/文昌位/缺角…）。
**禁用**：空泛吉祥话（走红运、发大财）｜纯理论无自查钩子的长篇｜`#我要上热门` 这类蹭热点无关词当主标题。

### 封面动词要白话，别用行话当钩子

行话可以极少量存在于正文知识点里，但封面大标题优先「大家一眼就懂」：

| 偏行话 | 更接地气 |
| --- | --- |
| 冲了 / 门冲 | 正对 / 对着 |
| 关不住 | 留不住 / 捂不住 / 兜不住 |
| 受冲、直冲 | 正对 |

例：`大门冲了这三样，钱财关不住` → `大门正对这三样，钱财留不住`。

### 专名怎么用

- 可搜、用户会搜的：床位、大门、文昌位、缺角 → **标题里保留**
- 流派口诀/术语（火烧天门、门冲）：可进正文或副信息；**别拿最生僻的字当封面动词**，除非像「火烧天门」已被数据验证能带播放

## §受众（比图文号年长很多）

- 年龄：**50 以上 / 41-50** 交替居首，偶见 31-40。
- 地域：**广东**居首（近 8 篇多次），新一线为主。
- 职业：白领 / 制造业 / 服务业 / 农林牧渔 / 非工作人员 交替。
- 性别：后台常未提取到明确男女占比，暂缺。
- 同类作者（找选题空白）：林旭易学、刘老师户型解析、郭璞研究会、武当丸子、东方术数、哲学本质论、朱汉宇日子馆，以及泛流量的涂磊/新闻姐/人民网。

**动作**：写给「关心自家住宅、想照着调一调」的中年及以上受众；术语首现一句话解释；多给能对照自家的判断句。

## §标签（话题）写法

抖音标签不承担主分发（推荐靠算法读内容），作用是**被搜到** + 内容归类。固定 **3–5 个**，别堆空泛国学词。
结构：1–2 个**可搜具体词**（跟本期主题，如 #卧室风水 #床位摆放）+ 1 个垂类池词（#家居风水/#阳宅风水）+
1 个爆款验证的大词（#传统文化涨知识）+ 可选 1 个自建栏目词（#阳宅篇）。
少用：一次堆 5 个以上；全是「#国学智慧认知觉醒」这类无人搜的空泛词。

## §封面

低播放作品的封面点击率后台常为 0%/未知，不可信；不要据此下结论。封面结构保留风水固定模板
（朱红两行大标题 + 诗意泥纸背景 + 顶栏固定文案），变化只发生在**文案层**（把选题写成「对照自家」的自查钩子）。

## §脚本已知局限（非数据结论，供下次运行排障）

- `fengdashi-analyze.mjs` 的 `openSeries()` 按**标题去掉「（上/中/下篇）」后的完全相等**匹配连载，一旦上/下篇标题措辞不同（如《家里六大煞，一件物就化（上篇）》配《化煞物这样对症用，记牢四禁忌（下篇）》），会误报「未收尾连载」——实际该系列已在 2026-08-10 用《化煞物…（下篇）》接住上篇预告（内容对得上：三件万能化煞物 → 对症处方+四禁忌）。**每次报告出现「未收尾连载」时，先去数据库核对该上篇预告的内容是否已被近期某篇标题不同但内容对应的记录接住**，不要机械按标题字符串判断。
- `scripts/export-pages-with-bgs.mjs` 原来硬编码只识别 `caishen-bg-*.png/jpg` 命名的背景图（历史上是从财神号脚本复制而来），且没有带 `X-Era-Auth` 鉴权头会被本地 Agent 401 拒绝。已在本轮修复：现在会自动识别 `--bg-dir` 下任意 png/jpg（无 `caishen-bg-` 前缀也可），并复用 `era-auth-core.mjs` 的内置鉴权哈希。
- **诗意背景生成工具偶发拦截**（2026-08-11 第四篇遇到）：诗意 reference 背景依赖聊天内建图像生成工具，本轮该工具把调用判定为"非用户明确请求"并拒绝（提示不要重试）。遇到这种情况**不要**卡在这一步或整轮判失败，直接跳过 `overlayStacked`/`backgroundType: reference` 那一层，改用普通 `POST /v1/projects/:id/export` 走 Era 默认 `pageOverlay: fengshui` 内置纹理（冷蓝雾色村舍底图，全篇自动同色调），照常完成上传入库+推飞书；只在通知/highlights 里注明这次缺专属插画，供后台核对播放数据时参考。
