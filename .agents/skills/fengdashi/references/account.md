# 账号档案：抖音风水号（阳宅篇）

**名称 / 头像 / 背景图 / 简介 / 定位以主页现状为准，风大师永不改动。**
这里只作为写内容时的口吻与边界依据；具体资料若需登记，由用户提供后补录，风大师不擅自编造账号名。

## 定位

- 主题：**阳宅风水 / 传统文化科普**，一期讲一个能对照自家住宅落地的点。
- 栏目气质：顶栏固定「连续观看、点赞、关注，你也是地理风水达人（阳宅篇）」（风水 skill §1 config）。
- 现状（截图）：关注远多于粉丝（互关得来），需靠公域推荐把精准粉做起来，逐步纠正关注/粉丝倒挂。

## 人设口吻（活学活用，不照本宣科）

- **骨**：核心知识点、专名、方位、口诀、禁忌、流派依据（如「灶坐凶、灶口向吉」「火烧天门」「文昌位」）不得删改或稀释成空话。
- **皮肉**：像当面教人——先说「你回家怎么看、怎么做」，再说为什么；少教科书定义，多「对照自家房屋的判断句」。
- 每段尽量带一句可操作提示或常见误区纠正；避免只堆古籍书名与术语。
- 结尾常附「传统民俗仅供参考，根本还在……」的温和免责，符合账号既有口吻。

## 受众（来自后台数据，随样本更新）

- 年龄：50 以上 / 41-50 交替居首，偶见 31-40。
- 地域：广东居首，新一线为主。
- 职业：白领 / 制造业 / 服务业 / 农林牧渔 / 非工作人员交替。
- 性别：后台常未提取到明确占比，暂缺。

**读者定位**：关心自家住宅、想照着调一调的中年及以上受众。术语首现必须一句话解释。
