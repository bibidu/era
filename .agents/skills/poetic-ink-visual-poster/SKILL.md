# 写意意象图（无文字）

把用户给出的**主题 / 大纲 / 版面描述**编译成一张「角落意象群 + 大面积泥纸留白、画面零文字」的竖版写意图。视觉语言与 `poetic-ink-quote-poster` 一致，但**禁止出现任何汉字、字母、数字、标点、署名、水印或伪文字**。

本 skill 由 [poetic-ink-quote-poster](https://github.com/Yuuhann1999/poetic-ink-quote-poster) 改编：去掉题名/正文/作者排版层，改为从大纲提炼可成像的抽象隐喻。

## 默认模式

始终使用 **Standard / 写意标准模式**，直接调用内置 image generation 生成位图。除非用户明确要求只要 Prompt，否则必须同时返回生成图和最终 Prompt。

固定视觉骨架：

- 竖版画面（优先 3:5；生成工具无 3:5 时用 9:16 或 3:4），无边框、无样机、无投影。
- 画面约 70%-85% 是干净的单色泥纸背景；只保留很轻的纤维和矿物颗粒。
- **画面上不出现任何文字**（含题名、正文、署名、日期、页码、logo、水印、伪汉字）。
- 默认：画面上方或左上/右上/上中偏侧放一个小型抽象意象群，约占画面 15%-28%；由 2-4 个有主次关系的轻量形体组成，来自主题/大纲的一个核心隐喻。
- **作图文页背景时（背景图模式）**：意象群必须落在**左下角或右下角**二选一（可随机，但单张内固定一角），约占画面 15%-28%，贴底但不贴死边；上半与中部大面积留白供正文叠字。Prompt 须写明 `bottom-left` 或 `bottom-right`。
- 意象群之外保持呼吸感与大面积留白；允许叠墨、纸片、线、淡色气韵，但不把意象铺成完整风景或商业插画。
- 原 skill 中下部文字区在默认模式下继续留白；背景图模式则把意象放到下角，中上留白。

## 输入解析

1. 用户可能只给主题（如「厨房风水」）、分点大纲、或版面描述。不要把大纲原文抄进画面。
2. 从整段内容中只提炼**一个最能成像的核心关系**，例如「灶坐凶、灶口向吉」可转成「压在暗墨石上的灶火剪影 + 朝向淡墨吉气方向的开口与一缕暖烟」，而不是画出整间厨房。
3. 若大纲含多个大章节：默认**每章一张图**（各自一个核心隐喻）；用户只要一张总图时，合并为一个总隐喻，不堆叠叙事。
4. 情绪只作为色纸和墨色的温度：安宁、护佑、克制、警醒、明净等，不用文字解释情绪。
5. 不需要核实作者出处；也不要在图中写出处。

## 泥纸与颜色

背景选择一种干净的低饱和底色：米白宣纸、暖灰、浅青瓷、雾蓝、淡赭土、灰紫或很浅的藕粉。根据主题情绪选择，不要同时使用多种背景色。背景要像哑光手工泥纸：细纤维、轻微矿物颗粒、吸墨、平整、无油光；不要有明显褶皱、污渍、纸张卷边或强烈旧化斑驳。

意象使用同一色系的深墨、淡墨和至多一处温和的矿物色（如极淡赭火、浅青水意）。颜色只服务于意象，不做高饱和色块，不做霓虹，不做彩色拼贴。整张图建议不超过背景色、墨色、一个辅助色三种可辨颜色。

## 意象群选择

不要只画一个孤立图标。先选一个主结构，再叠加 1-3 个轻量辅助层：

- **主形：** 一枚水墨剪影、纸片形、断裂线或不完整物件，承担主题的核心关系。
- **次形：** 一个尺度更小、颜色更淡的呼应形，例如墨石、月缺、远点、植物枝、纸边、烟痕或影子。
- **过程层：** 1-2 条干笔线、渗墨边、半透明纸片、细颗粒或被擦除的印刷痕迹。
- **气韵层：** 一小块淡墨晕、云气、留白缺口或轻微透明叠色，只在需要时使用。

目标是一个占画面 15%-28% 的小型意象群：1 个清晰主形、1-2 个辅助形、至多 1 个过程/气韵层。只保留一个核心关系，不画完整人物、完整建筑、完整山水或连续叙事。意象可放在左上、右上或靠近上中部，避开边缘。

风水 / 宅居类主题时，优先用抽象器物与气场关系（灶火、烟缕、水线、方位开口、压煞墨石），避免写实户型图、罗盘刻度、八卦符咒文字。

## 变化配方

每次生成前选择一项布局、一项意象处理和一项纸色；主骨架不能改变。

| 布局 | 意象处理 | 适用感觉 |
| --- | --- | --- |
| 右上意象群 + 大面积中下留白 | 主形水墨剪影 + 墨石/云痕辅助层 | 清醒、明净、古典 |
| 左上意象群 + 大面积中下留白 | 断裂水墨线 + 远点 + 半透明纸片 | 行旅、警醒、回望 |
| 上中偏侧意象群 + 大面积中下留白 | 纸片留白形 + 烟缕/淡墨晕 | 护佑、含蓄、烟火 |
| **右下意象群 + 大面积中上留白**（背景图） | 主形水墨剪影 + 墨石/烟痕 | 图文页背景、叠字 |
| **左下意象群 + 大面积中上留白**（背景图） | 断裂线 + 纸片/淡墨晕 | 图文页背景、叠字 |

## Prompt 编译器

将最终 Prompt 写成四个紧凑段落，顺序固定：

1. **画布与留白：** 竖版整幅泥纸底、单色背景、留白比例、意象群的准确位置；明确中下部与底部均为空白，无文字区。
2. **主题隐喻与意象群：** 用一句话点明主题核心关系（勿抄大纲原文进图），说明由 2-4 个形体组成的意象群、大小、层次和墨色处理。
3. **材质：** 泥纸纤维、吸墨、轻微印刷颗粒和柔和漫射光；强调水墨写意而非摄影写实。
4. **气质与禁用项：** 安静、写意、抽象、克制但有层次；完整禁用：任何文字/伪汉字/数字/署名/水印/logo/CTA、完整场景、复杂背景、孤立图标、狂草书法装饰字、商业标题、3D、霓虹、卡通、摄影写实。

Prompt 必须是具体的可渲染指令。优先写“右上角一枚不完整的灶火淡墨剪影，下压一枚深墨石，一缕暖烟斜向留白开口”这类可成像句子。

## 工作流

1. 读取用户主题/大纲/版面描述，确定章节切分、情绪、一个视觉关系。
2. 每张图选择布局配方、纸色、墨色和一个 2-4 层的意象群。
3. 按四段 Prompt 编译器写最终 Prompt，并强调 **absolutely no text of any kind**。
4. 使用内置 image generation 生成；风格应对齐上游示例（https://github.com/Yuuhann1999/poetic-ink-quote-poster/tree/main/examples），生成时可下载 1–2 张示例作 `reference_image_paths`。
5. 检查：是否零文字、意象群是否有主次、是否仍有 70%-85% 留白、是否风格一致。
6. 若出现文字、意象变成完整厨房/风景、背景变脏，只做一次针对性重生。
7. **交付（非社媒）**：上传图后用 `node scripts/make-oss-preview-html.mjs --title … --image …` 生成 HTML 预览页，对话框**只发 HTML URL**；**禁止**直发 OSS 图链。询问用户用完是否删除该预览文件。若属于社媒帖子则按图文 skill 入库并发自建站链接。返回 HTML 链接、最终 Prompt、配方与一句意象解释。

## 负面约束

始终避免：任何文字与伪文字、满幅风景、完整叙事插画、人物肖像、复杂山水、孤立单符号、花哨拼贴、海报广告层级、粗大标题、书法装饰字、水印、logo、CTA、渐变 UI 背景、塑料油光、明显褶皱、强阴影、立体透视、3D、霓虹、赛博朋克、动漫、可爱卡通、摄影写实、多色装饰、户型平面图、可读罗盘刻度。

## 质量门槛

完成前确认：

- 画面是否完全没有文字、数字、署名、水印？
- 是否有一个角落意象群，包含清晰主形和 1-3 个克制的辅助层？
- 是否有 70%-85% 的干净单色泥纸留白？
- 背景是否平整、哑光、纤维细微？
- 是否只有背景色、墨色和至多一种辅助色？
- 是否与 poetic-ink-quote-poster 气质一致（克制写意，而非商业插画）？
- 是否真的调用并生成了图片？

## 示例请求

- `按这个版面描述生成写意配图，风格同诗句海报但去掉全部文字。`
