## §发布节奏（平台硬约束，优先级高于一切软优化）

抖音有**断更惩罚**：上一次发布后最晚第 3 天必须再发，即相邻两篇间隔 **≤ 2 天**。
约束是**账号级**的，风水 / 健身也占发布位。

账号历史踩过 3 次：

| 断更 | 间隔 | 之后那篇的播放 |
| --- | --- | --- |
| 07-17 → 07-20 | 3 天 | 434 |
| 07-23 → 07-28 | 5 天 | 257 |
| 07-31 → 08-03 | 3 天 | 662 |

三次全部落在 257–662；而间隔合规又是早发的四篇是 4249 / 3379 / 11000 / 633。

08-03 之后节律已经接上：08-03 → 08-04（1 天）→ 08-05（2 天）→ 08-06（1 天，第 17 期）
→ 08-08 风水上篇（2 天）→ 08-10 风水下篇（2 天）→ 08-11（1 天，第 18 期）全部合规，
连续 7 篇不触红线。等这段跑满两周，断更惩罚的残留应当清零，届时星期数据要整体重算。

风水篇实测确实在替图文占位：08-06 → 08-11 之间图文空了 5 天，全靠 08-08 / 08-10 两篇风水把间隔压在
2 天以内。所以**排期必须按账号级算**，只看图文会误判成已经断更。

**排期规则**：固定周节律 **周一、周二、周三、周四、周六**（`PLAN_WEEKDAYS`）。这是唯一同时做到
「相邻间隔全部 ≤ 2 天」和「占住三个黄金档」的排法：周四→周六 2 天、周六→周一 2 天，其余 1 天，
只让出实测最差的周五和无样本的周日。**不要**用「窗口内挑星期优先级最高」的贪心排法，那会滑成
周三→周四→周五→周六→周一，反而把周二漏掉。

**结论**：

- **周一差无法单独归因**：08-03 同时踩了 3 天断更，662 里有多少是周一、有多少是断更惩罚，现有样本分不开。按「周一真实水平大概率高于周五」处理（`WEEKDAY_PRIORITY` 里周一 3 > 周五 2），等补到一篇间隔合规的周一早发再回来修。
- **周二早发第一枪是 757**：证明「周二 257」主要是时段拖的，但 757 还没进四位数，`WEEKDAY_PRIORITY` 周二保持 4，先再补一篇。
- **周三仍是最肥**：中位 3663、峰值 1.2 万（暗号），划走率 39.71% 是全场最低。
- **周六早发第一枪 1127**：间隔 2 天、07:40、划走 43.94%，四位数；节律里的周六不是死档，但只有 1 篇，`WEEKDAY_PRIORITY` 先不动。
- **时段的影响强于星期**：下午发的周四只有 47 播放。

**动作**：优先级 `断更约束 > 时段 > 星期`。节律不变：周一、周二、周三、周四、周六早 07:40。

### 第 16 期实测：页数结论成立，吸粉结论没成立

第 16 期（08-05 周三 07:40，3077 播放）是**第一篇完整按新规则做的作品**（5 页、期数放末页——当时规则还带下期预告、
每页翻页钩子、第 3 页可抄）。它一次验证、一次证否：

| 指标 | 第 16 期 | 同播放量级（3000–4300）参照 | 判定 |
| --- | --- | --- | --- |
| 平均浏览图片数 | **2.6** | 2.3 / 2.5 | ✅ 页数压到 5 页确实把这项抬到 2.5+ |
| 吸粉率 | **0.03%** | 0.09%（4249）/ 0.12%（4310）/ 0.13%（11000） | ❌ 同级最低 |
| 收藏率 | 0.29% | 0.64% / 1.02% / 0.58% | ❌ 同级最低 |

吸粉率必须按播放量级比：3000 以上的篇目吸粉率天然落在 0.09%–0.13%，拿 0.03% 去和第 11 期的 0.32%（633 播放）
直接比是不公平的——但 **0.03% 仍然只有同量级的四分之一**，所以「末页三件套自动抬吸粉率」这条**第一次执行没有兑现**。

同时收藏率也偏低，而本账号爆款特征恰恰是收藏 ≥ 点赞（第 16 期是收藏 9 < 点赞 16）。两项一起低，指向的是
**内容形态**而不是版面位置：第 16 期讲「同时开 3 个 Agent 不打架」，读起来是「他能做到」，读者没有拿走一份
自己今晚就能用的东西。第 3 页虽然是可抄页，但抄的是目录结构，不是能落地的判断清单 / 规则原文。

**动作（在原有硬规则之上加一条）**：可抄页要给**能落地的原文**（规则条文、prompt、判断清单；
命令仅当服务 AI 实践点时附带），不要给「结构示意」或「我的目录长这样」。可抄页落地句写成「可自行封装 skill，或写进 AGENTS.md。」不要「按仓库来」，不要「交给子 Agent」，不要「复制粘贴一下 / 直接粘给 Agent」。判断标准：读者截这一页，能不能不看正文就用起来。
**不要**把可抄页做成裸 git / CLI 教程页。

第 2 页顶栏放「第 N 期 + 朱红下划线 + 三行空白」＝把最贵的位置让给了栏目标识，读者还没拿到任何信息就划走。

**动作（已写进图文 skill 硬规则；第 23 期起）**：

- 全部内容页 `topText: '每天一个提效实操·第 N 期'`，`seriesLabel` **留空**（顶栏位置与「点赞关注不迷路～」相同、全宽灰线；不要朱红、不要三行空白）。末页正文**不要**再写同一句期数。对照实验（第 11 vs 12 期）仍记在上方：期数不要用 `seriesLabel` 占第 2 页顶栏
- 末页写关注理由 + 提问；期数只在顶栏；**禁止**再写「下期：…」预告
- 页数 ≤ 5（封面 + 4 个 `##`）——平均浏览图片数常年 1.8–2.7，多做的页没人看
- 每页末尾留一句翻页钩子（悬念或提问）
- Agent 量词用「个」不用「只」（「只审」=只负责审，不是量词）

涨粉 3，分母小所以这个百分比不能当天花板用；把它换算成绝对值更有意义：**293 播放换 3 个粉**，
而第 16 期 **3077 播放只换 1 个粉**。这两篇的差别不在版面（都是新版），在于前者给的是「哪三类别写」的判断清单，
后者给的是作者本人的工作方式。

**吸粉率必须分播放量级读**：
- 300 以下：分母太小，百分比噪声大，只看绝对涨粉数
- 600 左右：0.15%–0.32%
- 3000 以上：0.09%–0.13% 是常态，低于 0.05% 就是内容没给够

**动作**：末页固定两件套 —— 关注理由（一句身份认同）+ 一个提问（顺带拉评论进入率）。期数只出现在顶栏 `topText`，末页正文不要再写 `每天一个提效实操·第 N 期`。
**禁止**写「下期：…」连载预告（该策略已废止）。
但三件套只是**必要条件**：第 16 期当时三件套齐全、吸粉率仍是同级最低（见 §版面）。真正决定吸粉的是**这一篇有没有让读者
拿走一件能立刻用的东西**，末页只是把「拿走了、还想再来」翻译成关注动作。
