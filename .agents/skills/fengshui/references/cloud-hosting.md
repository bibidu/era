# 云托管与成片回链

风水竖版成片（`fengshui`）交付遵守：

1. 成片 / 封面帧若需落 OSS：走 `bash scripts/oss-upload.sh`（见 `docs/cloud-hosting.md`、skill **oss-upload**）
2. 对用户：**只发绑定本次 MP4 的实验室 HTTPS 专属预览深链**；链接单独一行
3. **禁止**对话框直发 OSS 裸链当唯一交付；**禁止**聊天塞视频附件
4. 勿发 HTTP 裸 IP（Safari 等安全上下文能力会丢）

## 根路径链接为什么会错

`https://39.106.179.17.sslip.io/` 是通用 SPA 首页，`?tab=data` 是通用社媒数据页；两者本身都不携带本次上传 MP4 的对象标识。上传 OSS 与打开首页是两个彼此独立的动作：即使首页返回 HTTP 200，也不代表页面加载了本次成片。前端没有成片播放器或专属路由时，根路径只会落到默认页、历史内容或空页面。

过去错误交付的直接原因是只检查了“站点能打开”，没有检查播放器实际请求的对象、起播结果和视频时长。

## 强制验收

1. 每条成片必须有唯一深链，且深链能解析到本次 MP4。
2. 用无登录新会话打开；核对网络请求中的对象 key / URL 与上传结果一致。
3. 实际起播并核对时长；403、过期签名、落回首页、旧视频均视为失败。
4. **禁止**将裸根路径或通用 `?tab=data` 作为成片交付。
5. 当前端尚无专属播放器 / 路由时，标记“预览发布阻塞”，不要伪造已就绪链接。
