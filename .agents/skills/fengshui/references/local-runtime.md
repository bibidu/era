# 本机 VoxCPM 0.5（老者）

风水竖版成片的配音固定在用户 Mac 的**既有** VoxCPM 0.5 环境运行；不调用云机或 MiniMax，也不在任务中安装、下载或更新模型。

## 老者参考资产

- prompt 音频：`https://github.com/bibidu/bbd5213/blob/main/docs/voice/laozhe/laozhe-ref.wav`
- 精确参考文本：

  > 内心深处对他人的真实评价，尤其是一些不好的评价，一定要烂在肚子里。哪怕对方再不好，咱也别说对吧。因为你一旦说出口了，有可能会引起没有必要的矛盾和纷争，没必要去为自己树敌。

参考音与这段文本必须成对传给现有 runner；不得用其他声线或自行改写参考文本替代。

## 启动门槛

1. 检查 `memory_pressure`。出现 throttled pages 时直接等待；不能只凭 “System-wide memory free percentage” 判定安全。空闲页与可回收页都很低、同时压缩器或 swap 正在增长时，也视为无安全窗口。
2. 与用户正在运行的 ASR、OCR、嵌入、其他 TTS、FFmpeg/Remotion、Blender 互斥；并行任务尚未让出安全窗口时等待。不暂停、杀掉或降级用户的现有任务。
3. 只运行一个合成单元，确认其输出可解码后才继续下一单元；整片编码在所有配音停止后单独进行。

预检只降低风险，不能承诺本机绝不崩溃。预检不通过时，报告正在等待的条件；不要把云机、MiniMax、别的声音或未验证的本地环境当作替代。
